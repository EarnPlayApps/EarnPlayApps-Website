# EarnPlayApps Website

Mobile-first official studio website starter.

## Deploy with Cloudflare Pages
1. In Cloudflare Dashboard, open **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
2. Select `EarnPlayApps/EarnPlayApps-Website`.
3. Production branch: `main`.
4. Framework preset: **None**.
5. Build command: leave blank.
6. Build output directory: `/` (repository root).
7. Deploy.

## Before public launch
- Upload verified APKs and set their paths in `apps.json`.
- Add final app icons, screenshots, version numbers and release notes.
- Replace draft Privacy Policy and Terms with accurate reviewed documents.
- Add and verify the official support email.
- Test every page and download link on mobile.
- Keep checkout disabled until payment provider, refunds, tax and customer support are ready.

The app directory currently lists All Convert, QR Scanner and E-Calculator as **In development**. No APK download is enabled.
